# Approved MCP records

Generated by the governance scripts. Do not edit by hand.

A row here means the record — declared identity, transport, auth model, and known tool descriptions —
passed static review. It does NOT mean this repository controls whether the real server is connected in
any given environment: that lives in each machine's own Claude Code / connector configuration, entirely
outside this repository. Treat every MCP tool's actual runtime output as untrusted regardless of this
listing. See `rules/policy.md` for the MCP trust boundary and the separate per-session adoption gate.

- [figma](figma.md) — Claude.ai-hosted Figma connector (claudeai-proxy) for reading Figma files and designs from within a session. (transport: http, auth: oauth)
- [mdk_site](mdk_site.md) — Project-local MCP server from the MDK monorepo's own @tetherto/mdk-mcp package, exposing site/fleet query and control tools (via examples/mvp-site's mcp-plugins/site plugin) over HTTP on localhost. (transport: http, auth: none)
- [playwright](playwright.md) — Microsoft's official Playwright MCP server for browser automation (navigate, click, type, form-fill, snapshot/screenshot) via Claude Code's own MCP configuration. (transport: stdio, auth: none)
