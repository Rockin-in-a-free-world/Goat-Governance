# MDK docs style

Read [`references/style.md`](references/style.md) before authoring or editing Markdown prose. It is a verbatim copy of
`docs/reference/maintainers/style.md` from the public `tetherto/mdk` repository at tag `v0.10.0`; the source repository
is authoritative and a newer tag returns through candidate review.

Apply the rules to pages you touch. Do not mass-rewrite existing files unprompted.

Links inside `references/style.md` to other `tetherto/mdk` files (`single-source-of-truth.md`, package READMEs) point
into that repository, not this one.
