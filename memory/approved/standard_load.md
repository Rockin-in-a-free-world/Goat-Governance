## Standing context

This public repository ships no real shared memory. Keep your team's `standard_load` and other entries in a private
clone with the same layout (`memory/`, `registry/approved-memory.json`, `rules/scanning-rules.json`) and run the
memory scripts against it with `--root <path>`. The steps are in `docs/share-memory.md`.
